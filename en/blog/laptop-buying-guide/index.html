How to choose a laptop without overpaying

The best laptop is not necessarily the one with the longest specification list. First match its configuration to your actual work, study or gaming needs.

← All English guides

1. Start with your workload

For web browsing, office documents and video calls, prioritize a modern processor, a comfortable display, sufficient memory and a reliable SSD. Photo editing, programming with several tools open or video production can benefit from additional RAM and sustained processor performance. Modern games and GPU-intensive software may require dedicated graphics.

Compare the exact processor model and generation. Two laptops advertised as “Core i5” or “Ryzen 5” can perform very differently. Look for independent benchmarks of the specific CPU and, ideally, the laptop model.

2. Memory and storage matter every day

For many multitasking buyers, 16 GB RAM is a practical baseline; demanding creative work may justify more. Confirm whether the memory is soldered, installed in slots or upgradeable. An SSD improves startup and application responsiveness compared with a traditional hard drive, but capacity and expansion options matter too.

  • Verify installed RAM and the maximum supported capacity.
  • Confirm SSD size, interface and whether an extra slot is available.
  • Check whether storage or memory upgrades affect warranty terms.

3. Gaming and screens: check the complete configuration

For a gaming model, the exact GPU is only part of the story. Graphics power limits, cooling, screen resolution and performance tests of the same configuration influence frame rates. A high refresh rate is useful only when the system produces enough frames and the connection supports the display mode.

Also assess screen brightness, color gamut, keyboard layout, battery life, size and weight. A model that is fast on paper may still be inconvenient to carry every day.

4. Before checking out in Brazil

  • Match the full model code, RAM, operating system and keyboard layout to the listing.
  • Check whether the laptop ships with Linux or Windows and whether licenses are included.
  • Review seller rating, Brazilian warranty coverage, return policy and shipping cost.
  • Compare the final Pix, card or installment price; do not treat a crossed-out number as price-history proof.
